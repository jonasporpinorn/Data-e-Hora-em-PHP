Visão geral

As funções principais

date()

Formata uma data e/ou hora local.

mktime()

Devolve o timestamp Unix de uma data.

strtotime()

Converte um texto de data em inglês para timestamp Unix.

time()

Devolve o timestamp Unix do momento atual.

date_default_timezone_set()

Define o fuso horário padrão do script.

date_default_timezone_get()

Consulta o fuso horário padrão em uso.

O que é um timestamp Unix?

É o número de segundos desde 01/01/1970 às 00:00:00 GMT. É assim que o PHP guarda uma data por dentro. As funções acima servem para ir e voltar entre esse número e uma data legível.

date()

Formatando a data

A função date() transforma um timestamp em texto legível. O primeiro argumento é o formato, obrigatório. O segundo é o timestamp, opcional: sem ele, vale o momento atual.

date(formato, timestamp)

Monte seu formato

Digite ou clique nas letras para inserir. Para escrever uma letra literal, use barra invertida antes dela, por exemplo \d.

date_default_timezone_set()

    
Fuso horário

  

  
A função date() usa a hora do servidor. Muitos servidores de hospedagem ficam em UTC, e seu site mostraria a hora errada para o Brasil. Para acertar, defina o fuso antes de usar date().

  
<?php
date_default_timezone_set("America/Sao_Paulo");
echo "Data e hora: " . date("d/m/Y H:i:s");
echo date_default_timezone_get();   // America/Sao_Paulo
?>

time()

    
O timestamp de agora

  

  
Sem argumentos, time() devolve os segundos desde 1970 até este instante. Combine com date() para deixar legível.

  
<?php
$ts = time();                          // timestamp atual
echo date("d/m/Y H:i:s", $ts);         // data legível
?>

Exercício

    
Qual retorna o ano completo?

  

  
$d = strtotime('10:30pm May 5 2025');

  
Qual é a sintaxe correta para retornar o ano completo (2025)?

  

    
    
    
  

  

  
O Y maiúsculo dá 4 dígitos (2025). O y minúsculo dá só 2 dígitos (25). E YYYY imprimiria o Y quatro vezes, porque cada letra é interpretada separadamente.

Nomes em português

  
date() sempre responde em inglês. Para "domingo, 15 de novembro de 2026", use IntlDateFormatter (precisa da extensão intl) ou arrays.

  

    
<?php
$fmt = new IntlDateFormatter(
    'pt_BR',
    IntlDateFormatter::FULL,
    IntlDateFormatter::NONE,
    'America/Sao_Paulo',
    IntlDateFormatter::GREGORIAN,
    "EEEE, d 'de' MMMM 'de' yyyy"
);
echo $fmt->format(new DateTime());
?>

    
<?php
$dias = ['domingo','segunda-feira','terça-feira',
  'quarta-feira','quinta-feira','sexta-feira','sábado'];
$meses = [1=>'janeiro','fevereiro','março','abril',
  'maio','junho','julho','agosto','setembro',
  'outubro','novembro','dezembro'];

$h = new DateTime();
echo $dias[$h->format('w')] . ', '
   . $h->format('j') . ' de '
   . $meses[(int)$h->format('n')] . ' de '
   . $h->format('Y');
?>
